# CompareXAI

## A Simple Library for Comparing Explainable AI Methods

CompareXAI is a project for comparing different Explainable AI
(XAI) methods using machine learning models.

## XAI Methods

- SHAP
- LIME
- Permutation Importance

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- SVM

## Dataset

The project uses the Wisconsin Diagnostic Breast Cancer dataset.

## Evaluation

The project compares the XAI methods using:

- Feature importance
- Spearman correlation
- Kendall Tau correlation
- Top-K feature agreement
- Runtime comparison
- ROAR evaluation

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- SHAP
- LIME
- Matplotlib
- SciPy
